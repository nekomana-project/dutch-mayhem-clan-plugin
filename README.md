# Dutch Mayhem Clan Discord Bot Plugin

A RuneLite plugin for members of the **Dutch Mayhem Clan (DMC)**. It bridges your OSRS client with the DMC Discord bot.

## Features

- Forwards clan chat messages to the DMC Discord bot.
- Tracks loot received in the wilderness (surface + Revenant caves) and reports it for loot splits sessions.

## Setup

1. Install the plugin from the RuneLite Plugin Hub
2. Open the plugin settings panel (search for **Dutch Mayhem Clan**)
3. Fill in the following fields — you can find the values in the DMC Discord:
   - **Clan Chat URL** — the endpoint for clan chat (posted in `#bot-info`)
   - **Wildy Loot URL** — the endpoint for wilderness loot tracking (posted in `#bot-info`)
   - **Personal Token** — run `/mytoken` in the DMC Discord to get your token
4. Enable or disable **Track Wilderness Loot** as you prefer
